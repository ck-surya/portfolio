# Chhotu Kumar - Portfolio

Static portfolio for Chhotu Kumar, a software developer focused on backend systems, infrastructure automation, and reliability work.

The site highlights:

- Ubuntu, Docker, Bash, and Ansible work at Justuju
- Hetzner-to-AWS media migration with rclone
- Firebase phone verification and notifications
- Public DOMjudge and Mattermost deployment repositories

Open `index.html` in a browser, or serve the repository with a local static HTTP server. The downloadable resume is embedded in the homepage as a PDF data link.

The homepage is designed for GitHub Pages at https://ck-surya.github.io/portfolio/. Links and assets are relative to the repository path.
